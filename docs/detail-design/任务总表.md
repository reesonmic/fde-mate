## 任务认领流程

```
1. 在本总表中按里程碑（M2/M3/M4）和角色（FE/BE/AI/OPS/QA）筛选 Task
2. 在任务管理系统中认领（任务 ID 保持一致）
3. 创建 feature 分支：feat/{Task-ID}-{kebab-desc}
   例如：feat/M4-AI-004-rag-engine
4. 按 Task 描述中的"涉及文件路径"在 workspace/ 对应目录下编写代码
5. 自测通过后提 MR：MR 标题 = Task 标题；描述中链接 Task ID
6. Code Review 通过后合并 → 更新任务状态为 Done
```
