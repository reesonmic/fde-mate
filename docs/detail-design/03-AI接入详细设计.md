## 一、服务定位

- **独立部署**的 AI 编排服务（与业务 API 物理隔离）
- 对外提供 HTTP SSE 接口 `/ai/chat`，被 `api/` 通过 HTTP 调用
- 多 Agent 编排（Router + 5 子 Agent：T/P/C/F/Chat）
- RAG 引擎（HybridRetriever：向量+ES+RRF+Rerank）
- 多模型路由 + 熔断 + 降级

## 四、API 接口

### 4.1 `/ai/chat`（POST）- SSE 流式对话

**请求体**：
```json
{
  "assistantId": "tasks",
  "sessionId": "optional-session-id",
  "message": "本周有哪些待办任务？",
  "mode": "smart",
  "context": {},
  "mentions": []
}
```

**响应**（SSE 流）：
```
data: {"type":"token","delta":"收到"}
data: {"type":"token","delta":"关于"}
data: {"type":"token","delta":"任务的查询"}
data: [DONE]
```

**错误响应**：
```
data: {"type":"error","message":"LLM 服务不可用"}
data: [DONE]
```

### 4.2 `/health`（GET）

```json
{"status": "ok", "service": "fde-ai-orchestrator"}
```

### 4.3 `/ai/preview-action`（POST）

预览 AI 生成的操作，返回 actionCard 数据。

### 4.4 `/ai/execute-action`（POST）

执行已确认的操作。

### 4.5 `/ai/rag/search`（GET）

RAG 混合检索（Milvus 向量 + ES 全文）。

## 五、LangGraph 工作流

### 5.1 Agent 状态

```python
class AgentState(TypedDict):
    messages: list[dict]        # 对话历史
    assistant_id: str           # T/P/C/F/Chat
    mode: str                   # smart/creative/rigorous
    context: dict               # 页面上下文
    response_chunks: list[str]  # 流式响应块
```

### 5.2 当前架构（v1）

```
input → agent_node(LLM + system_prompt) → SSE output
```

### 5.3 目标架构（v2）

```
input → router_node → [task_agent | project_agent | coach_agent | file_agent | chat_agent]
  ↓
  └─→ 每个 agent 包含：LLM + tools + RAG → output
  ↓
safety_guard → SSE output
```

## 六、Prompt 管理

### 6.1 系统 Prompt 模板

每个助手有独立的系统 Prompt，通过 Jinja2 渲染：

| 助手 | Prompt ID | 说明 |
|------|-----------|------|
| T助手 | `task` | 任务管理、批量操作、风险分析 |
| P助手 | `project` | 项目进度、周报生成、里程碑跟踪 |
| C助手 | `coach` | 最佳实践、经验分享、学习路径 |
| F助手 | `file` | 文件搜索、内容分析、差异对比 |
| Chat | `chat` | 通用问答、分析总结 |

### 6.2 Prompt 渲染示例

```python
from app.orchestrator.prompts import get_system_prompt

prompt = get_system_prompt("task", mode="smart")
```

## 八、RAG 引擎（待实现）

### 8.1 检索流程

```
query → Embedding → Milvus 向量检索 → Top-K
  ↓
query → ES 全文检索 → Top-K
  ↓
RRF 融合 → Rerank → Top-N results
```

### 8.2 Embedding 模型

- 使用 DashScope text-embedding-v3
- 向量维度：1024
- 存储：Milvus collection `fde_documents`

### 8.3 分片策略

- 按段落分片（max 500 chars, overlap 50）
- 支持 PDF/Word/TXT 文件解析
