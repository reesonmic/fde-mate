## 一、产品定位

### 1.1 一句话定位
**面向 FDE（Forward Deployed Engineer，前线部署工程师，对标 Palantir 同名核心岗位）的 AI 原生工作台，让交付更可控、更高效、更专业。**

### 1.2 解决的核心问题

| # | 当前痛点 | FDE 工作台的解法 |
|---|---------|------------------|
| 1 | **信息分散**：任务在 Aone、项目在 Yuque、客户在 CRM、文件在 OSS，每天跨 5+ 系统切换 | **一站式工作中枢**：聚合任务/项目/客户/文件/学习，一处搜索全局可达 |
| 2 | **能力依赖个人经验**：新人 onboard 难、最佳实践沉淀难 | **FDE 教练 + 最佳实践库 + 专家 AI 问答**：方法论数字化沉淀，10 年经验专家 AI 个性化辅导 |
| 3 | **AI 时代的工具孤岛**：通用 AI 不懂业务上下文，需要反复"喂 prompt" | **嵌入式 Copilot**：4 个专属助手随场景自动切换，自动感知页面上下文 |
| 4 | **写操作风险高**：通用 AI 直接执行操作，FDE 不敢用 | **写操作必预览**：所有 AI 写操作都先预览 actionCard，确认后才执行 |

### 1.3 价值主张

- 🎯 **效率**：任务平均创建时长缩短 50%，周报 / 风险报告自动生成
- 🤖 **智能**：4 个嵌入式 AI Copilot，覆盖每个核心工作场景
- 📚 **成长**：FDE 新人 Onboard 周期缩短 30%

## 三、核心场景

### 场景 1：晨间一站式查看（Dashboard）

**故事**：周一早上 9 点，吾明打开工作台，欢迎横幅显示"今天有 3 项 P0 任务、2 个客户会议、1 份周报待提交"。点击"帮我准备晨会"，AI 自动生成晨会摘要（昨日完成/今日计划/阻塞）。

### 场景 2：AI 协助任务管理（Tasks + T 助手）

**故事**：吾明对任务助手 T 说"创建一个明天截止的 P0 任务：完成客户A的POC方案"。T 自动生成任务预览卡（标题/优先级/截止/关联项目），确认后一键创建。

### 场景 3：项目实施 + 风险预警（Project + P 助手）

**故事**：吾明打开"阿里云A数据中台"项目详情。项目助手 P 自动绑定项目，主动告警："识别出 1 项高风险 - 数据接入滞后 5 天，可能影响 5/20 UAT 节点"，并给出处理建议。

### 场景 4：FDE 能力成长（Coach + C 助手）

**故事**：吾明问 FDE 专家 AI（C 助手）："这个阶段下一步该做什么？" C 基于"实施阶段"+"我的等级 P5"+10 年专家身份 prompt，推荐 5 个 Next Step + 1 个金牌案例（匹配度 92%）+ 1 个最佳实践 SOP。

### 场景 5：智能文件管理（Files + F 助手）

**故事**：吾明在文件中心选中"项目交付方案 v2.1.pdf"，文件助手 F 自动感知。问"对比下 v2.0 和 v2.1 的差异" → F 给出结构化差异报告。再问"把所有验收文档归档到客户验收/2026Q2" → F 列出 8 个匹配文件，确认后批量归档。

## 五、详细功能设计

### 5.1 工作台（Dashboard）

#### 5.1.1 欢迎横幅
- 时段问候（早上好/下午好/晚上好）+ 用户名
- 今日工作量摘要（P0/会议/周报）
- 2 个 AI 快捷入口：「帮我准备晨会」「我今天最重要的 3 件事」

#### 5.1.2 4 张统计卡（一行）
| 卡片 | 主指标 | 副信息 |
|------|--------|--------|
| 待办任务 | 8 项 | P0:3 · P1:4 · P2:1 |
| 在交付项目 | 4 个 | 项目名简列 |
| 项目健康度 | 78 平均分 | 3 绿 · 1 黄 · 0 红 |
| 本月专家 AI 提问 | 18 次 | 24h 平均响应 |

#### 5.1.3 任务看板（4 列）
- 列：待办 / 进行中 / 复核中 / 已完成
- 每张任务卡：优先级 tag + 关联项目 tag + 标题 + 截止时间
- 支持拖拽改状态（v1.1）

#### 5.1.4 三栏：日程 / 项目进度 / 学习推荐
- 今日日程：时间 + 标题 + 元信息
- 项目进度：项目名 + 进度条（按健康度配色）+ 阶段
- 学习推荐：方法论/最佳实践/案例混排

### 5.2 任务中心 + 任务助手 T

#### 5.2.1 页面功能
- **page-header**：标题「任务中心」+ 副标题「N 项待办 · 1 项逾期 · 本周新增 5 项」+ 工具栏（导入 / 看板视图切换 / 新建任务）
- **状态 tabs**（pill 风格）：全部 / 待办 / 进行中 / 复核中 / 已完成（带数量徽章），右侧另有 2 个特殊状态 tab：**本周到期**（红）/ **逾期**（红）
- **4 列 Kanban**（默认视图）：待办 / 进行中 / 复核中 / 已完成
  - 每张任务卡：优先级 tag（P0 红 / P1 橙 / 已完成 绿）+ 关联项目 tag（蓝）+ 标题 + 截止时间（图标 + 文案）+ 负责人头像（mini avatar）
  - 已完成卡：opacity 0.75 视觉降级，最后一张以「还有 N 项已完成 · 查看全部」省略

### 5.3 项目详情 + 项目助手 P

#### 5.3.1 页面功能
- **面包屑导航**：工作台 > 项目空间 > 项目名（如「阿里云A 数据中台交付项目」）
- **项目信息头**：项目名 + 状态 tag（实施中/验收中等）+ 客户等级 tag（战略客户）+ 元信息（负责人 / 8 名成员 / 周期 / 已完成 65%）+ **健康度环**（彩色 SVG conic-gradient 圆环 + 数字 + 健康指标）
- **7 Tabs**：概览 / 任务 12 / 里程碑 5 / 文件 24 / 风险 3 / 团队 8 / 时间线
- **里程碑时间轴**：5 个里程碑（M1-M5），状态分 已完成（绿✓）/ 进行中（蓝⚡）/ 待开始（灰）
- **双栏：项目成员 + 风险列表**
  - 项目成员：6 人 mini avatar 列表（含角色：项目经理/数据架构师/后端/前端/测试/运维），右上「+ 邀请」按钮
  - 风险列表：3 风险，按红（高）/ 黄（中）/ 绿（低）分级，含处理人
- **关键文档**：4 张文档卡（含文件类型彩色图标 + 大小 + 更新时间）

### 5.4 FDE 教练 + 教练助手 C（FDE 专家 AI）

> [!IMPORTANT]
> **重新定位**：FDE 教练 = **FDE 专家 AI 问答 + 最佳实践库 + 方法论库**。其中"专家 AI"本质是带有 FDE 资深专家身份 prompt（10 年交付经验）的 AI 对话，融合用户项目背景给出针对性建议。**不再包含 AI 对练（角色扮演式演练）**。

#### 5.4.1 页面功能
- **page-header**：标题「FDE 教练」+ 副标题「FDE 专家陪你 · 方法论 + 最佳实践 + 专家 AI 问答」+ 工具栏（我的学习进度 / 向专家提问 → 聚焦右侧 Copilot 输入框）
- **4 大入口卡**（一行，顶部 3px 渐变条）：FDE 专家 AI 问答（青）/ 最佳实践库（蓝）/ 方法论库（紫）/ 学习路径（橙）
- **最佳实践库**：5 大场景 tabs（项目启动 / 客户沟通 / 技术方案 / 风险管控 / 验收交付），每场景 6+ 实践卡（含场景图标 + 描述 + 适用阶段 + 阅读时长 + 评分）
- **方法论库 · 热门 SOP**：交付项目启动 SOP / 客户验收 SOP / 风险升级 SOP / 项目周报模板包，含下载次数 + 下载入口
- **为你推荐**：基于当前项目阶段，最佳实践 + 案例 + 专家问答 三类混排

> [!NOTE]
> 专家 AI 的入口直接体现在顶部 4 入口卡和右侧 Copilot 中，无需独立的 banner 区。

| 文档总结 | "总结下《项目交付方案 v2.1.pdf》的关键信息" | report 卡（核心/变更/范围 3 类信息） |
| 批量归档 | "把所有验收文档归档到 客户验收/2026Q2" | actionCard + impact list（8 个文件） |

### 5.7 AI 对话中心

#### 5.7.1 三栏布局
- **左栏（历史）**：新建对话按钮 + 搜索 + 历史列表（按今天/昨天/更早分组）
- **中栏（对话）**：标题 + 对话模式 tab（智能/创意/严谨）+ 消息流 + 输入区
- **右栏（上下文）**：已引用对象 + 智能推荐引用 + 对话设置

#### 5.7.2 @ 引用功能
- @ 弹窗：5 类 tab（项目/任务/客户/文件/案例）+ 搜索 + 列表
- 选中后自动添加为上下文 tag

| 状态危险 | 红 | #FF4D4F |
| 状态信息 | 蓝 | #1677FF |

#### 6.1.2 图标
- **风格**：Lucide 线性 SVG
- **规范**：24×24 viewBox / stroke-width 1.5px / round line-cap & line-join
- **数量**：50+ 业务图标，统一通过 SVG sprite 注入

#### 6.1.3 助手徽章
- 渐变方块字母徽章（圆角 8px）
- 3 种尺寸：sm 24px / md 32px / lg 40px / xl 56px

#### 6.1.4 状态 dot
- 6px 圆点 + 同色光晕
- 4 种状态：success（绿）/ warning（黄）/ danger（红）/ info（蓝）

### 6.2 Copilot 交互规范

| 状态 | 宽度 | 显示内容 |
|------|------|---------|
| 默认（展开） | 400px | Header / Context / Body / Input |
| 折叠 | 56px | 仅徽章 + 折叠按钮 |
| 隐藏 | 0px | 完全隐藏（Dashboard / AI 对话页） |

#### 6.2.1 Context 区
- 自动感知（页面上下文 tag）
- 可手动 @ 添加引用
- 每个 tag 可单独移除（× 按钮）

#### 6.2.2 推荐建议（chip）
- 每个助手提供 4 条建议问题
- 一键发送

#### 6.2.3 输入工具栏
- @ 引用 / 附件 / AI 增强 / 发送

#### 6.2.4 写操作必预览
- 所有写操作（创建/修改/删除/批量）必须先生成 actionCard
- actionCard 包含：标题 + 状态徽章（待确认/执行中/已完成）+ 字段对比（旧值 del / 新值 add）+ 影响列表
- 用户必须点击「确认执行」才会真正执行

### 6.3 4 类 AI 卡片规范

| 卡片类型 | 用途 | 关键样式 |
|---------|------|---------|
| **actionCard** | 写操作预览 | 边框高亮 + 状态徽章 + 字段对比（红/绿）+ impact 折叠 |
| **report** | 报告/总结 | 标题 + 风险等级（高/中/低）+ 描述 |
| **nextSteps** | 编号步骤 | 圆形数字 + 描述 |
| **searchResults** | 搜索结果 | 文件图标 + 名称 + 元信息 + 跳转按钮 |

### 6.4 响应式
- **主断点**：桌面端（≥1280px）
- **目标分辨率**：1440×900（FDE 标准笔记本）
- **三列布局**：Nav 240px + Main 1fr + Copilot auto
