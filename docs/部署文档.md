### docker-compose.yml 完整配置

当前使用的 `docker-compose.yml` (项目根目录)：

```yaml
version: '3.8'

name: fde-mate

services:
  api:
    build:
      context: ./workspace/api
      dockerfile: Dockerfile
    image: fde-mate-api:latest
    container_name: fde-mate-api
    ports:
      - "8080:8080"
    environment:
      - DATABASE_URL=mysql+pymysql://root:20260227@mysql-8.0:3306/fde_workbench
      - REDIS_URL=redis://redis:6379/0
      - JWT_SECRET_KEY=fde-mate-jwt-secret-key-2026-secure-32chars
      - AI_ORCHESTRATOR_URL=http://host.docker.internal:8090
    networks:
      - products-shared
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8080/health')"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 30s

  web:
    build:
      context: ./workspace/web
      dockerfile: Dockerfile
    image: fde-mate-web:latest
    container_name: fde-mate-web
    depends_on:
      api:
        condition: service_started
    networks:
      - products-shared
    healthcheck:
      test: ["CMD", "wget", "--spider", "-q", "http://localhost:80/"]
      interval: 30s
      timeout: 10s
      retries: 3
      start_period: 10s

networks:
  products-shared:
    external: true
```

## Docker 部署

### 1. 完整构建部署

适合首次部署或代码大幅更新：

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml up -d --build
```

### 2. 快速启动

镜像已存在时使用：

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml up -d
```

### 3. 停止服务

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml down
```

## 常见问题

### Q1: 构建太慢怎么办？

**原因**：每次复制大量文件，重新安装依赖。

**解决**：
1. 使用 `deploy dev` 开发模式，热重载无需构建
2. 已配置 `.dockerignore` 排除不必要的文件
3. 使用国内镜像源（已内置阿里云配置）

### Q2: 代码更新后未生效？

**原因**：Docker 使用了旧镜像缓存。

**解决**：
```bash
# 重新构建
deploy build

# 或者使用开发模式（无需重建）
deploy dev
```

### Q3: API 返回 HTML 而不是 JSON？

**原因**：前端代理配置错误或 API 服务未启动。

**解决**：
1. 检查 API 容器是否健康：`deploy status`
2. 检查网络连通性：
   ```bash
   docker exec fde-mate-web ping api
   ```
3. 重启服务：
   ```bash
   deploy restart
   ```

### Q4: 数据库连接失败？

**常见错误**：
```
Access denied for user 'fde_user'@'172.18.0.4' (using password: YES)
Can't connect to MySQL server on 'shared-mysql'
```

**检查步骤**：
```bash
# 1. 检查 MySQL 容器是否在运行
docker ps | grep mysql
# 应该看到: mysql-8.0 (不是 shared-mysql)

# 2. 测试 MySQL 连接
docker exec mysql-8.0 mysql -uroot -p20260227 -e "SELECT 1"
# 密码是 20260227，不是其他值

# 3. 检查 API 容器的环境变量
docker exec fde-mate-api env | grep DATABASE_URL
# 应该是: mysql+pymysql://root:20260227@mysql-8.0:3306/fde_workbench

# 4. 检查容器网络
docker network inspect products-shared
# 确认 mysql-8.0 和 fde-mate-api 都在同一个网络
```

**修复方法**：
```bash
# 修改 docker-compose.yml 中的 DATABASE_URL
# 使用正确的配置（参见"当前运行环境信息"章节）

# 重新部署
docker compose down api
docker compose up -d api
```

### Q5: 如何查看日志？

```bash
# 使用 skill
deploy logs

# 或查看特定服务
docker logs fde-mate-api
docker logs fde-mate-web
docker logs fde-mate-ai
```

### Q6: 如何完全重置？

```bash
# 删除所有容器和数据卷
deploy reset

# 手动方式
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml down -v
```

### deploy skill 命令

```bash
# 查看所有容器

docker exec -it fde-mate-api sh

# 重启单个服务
docker restart fde-mate-api

# 查看网络
docker network ls

# 查看资源使用
docker stats
```

### 数据库操作

```bash
# 进入 MySQL
docker exec -it mysql-8.0 mysql -uroot -p20260227

# 查看数据库
docker exec mysql-8.0 mysql -uroot -p20260227 -e "SHOW DATABASES;"

# 备份数据库
docker exec mysql-8.0 mysqldump -uroot -p20260227 fde_workbench > backup.sql

# 恢复数据库
docker exec -i mysql-8.0 mysql -uroot -p20260227 fde_workbench < backup.sql
```
