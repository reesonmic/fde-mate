## 快速启动

使用项目级 skill 一键部署：

```bash
# 方式1：快速启动（使用已有镜像）
deploy up

# 方式2：重新构建后启动（代码更新后使用）
deploy build

# 方式3：开发模式（热重载，推荐开发时使用）
deploy dev
```

访问地址：http://localhost:5173

默认账号：
- 邮箱：`admin@fde.local`
- 用户名：`admin`
- 密码：`admin123`

## Docker 部署

### 1. 完整构建部署

适合首次部署或代码大幅更新：

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml up -d --build
```

### 2. 快速启动

镜像已存在时使用：

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml up -d
```

### 3. 停止服务

```bash
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml down
```

## 开发模式

### 特点

- **热重载**：代码修改自动生效，无需构建
- **快速启动**：依赖缓存，秒级响应
- **日志实时**：错误立即可见

### 启动方式

```bash
# 使用项目 skill
deploy dev

# 或使用脚本
cd workspace/scripts/dev
./start-dev.sh

# 查看日志
./start-dev.sh --logs
```

### 开发模式架构

```
宿主机代码
    │ (Volume 挂载)
    ▼
Docker 容器 (node:20-alpine)
    │ (热重载)
    ▼
浏览器 http://localhost:5173
```

### 开发时修改代码

```bash
# 1. 启动开发模式
deploy dev

# 2. 修改代码...
# 前端代码: workspace/web/src/
# 后端代码: workspace/api/app/

# 3. 保存文件，浏览器自动刷新
# （无需任何重启或重建操作）
```

## 生产部署

### 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| Docker | 20.10+ | 容器运行时 |
| Docker Compose | 2.0+ | 编排工具 |
| MySQL | 8.0 | 数据库（可外挂） |
| Redis | 7.0 | 缓存（可外挂） |

### 生产配置步骤

1. **配置环境变量**

```bash
cp workspace/api/.env.example workspace/api/.env
# 编辑 .env 文件，设置生产环境参数
```

2. **更新配置**

修改 `workspace/infra/docker-compose/docker-compose.app.yml`：
- 数据库连接使用实际地址
- JWT 密钥使用强随机字符串
- 关闭 mock LLM，配置真实 API Key

3. **构建并启动**

```bash
deploy build
```

4. **检查健康状态**

```bash
deploy test
```

### 健康检查端点

```bash
curl http://localhost:8080/health
curl http://localhost:8090/health
```

## 常见问题

### Q1: 构建太慢怎么办？

**原因**：每次复制大量文件，重新安装依赖。

**解决**：
1. 使用 `deploy dev` 开发模式，热重载无需构建
2. 已配置 `.dockerignore` 排除不必要的文件
3. 使用国内镜像源（已内置阿里云配置）

### Q2: 代码更新后未生效？

**原因**：Docker 使用了旧镜像缓存。

**解决**：
```bash
# 重新构建
deploy build

# 或者使用开发模式（无需重建）
deploy dev
```

### Q3: API 返回 HTML 而不是 JSON？

**原因**：前端代理配置错误或 API 服务未启动。

**解决**：
1. 检查 API 容器是否健康：`deploy status`
2. 检查网络连通性：
   ```bash
   docker exec fde-mate-web ping api
   ```
3. 重启服务：
   ```bash
   deploy restart
   ```

### Q4: 数据库连接失败？

**检查步骤**：
```bash
# 1. 检查 MySQL 容器
docker ps | grep mysql

# 2. 测试连接
docker exec mysql-8.0 mysql -uroot -p20260227 -e "SELECT 1"

# 3. 检查 API 配置的数据库地址
docker exec fde-mate-api echo $DATABASE_URL
```

### Q5: 如何查看日志？

```bash
# 使用 skill
deploy logs

# 或查看特定服务
docker logs fde-mate-api
docker logs fde-mate-web
docker logs fde-mate-ai
```

### Q6: 如何完全重置？

```bash
# 删除所有容器和数据卷
deploy reset

# 手动方式
cd workspace/infra/docker-compose
docker compose -f docker-compose.app.yml down -v
```

## 命令参考

### deploy skill 命令

| 命令 | 功能 | 使用场景 |
|------|------|----------|
| `deploy up` | 快速启动 | 镜像已存在时 |
| `deploy build` | 构建并启动 | **代码更新后使用** |
| `deploy dev` | 开发模式 | **本地开发推荐** |
| `deploy logs` | 查看日志 | 排查问题 |
| `deploy status` | 查看状态 | 检查运行情况 |
| `deploy restart` | 重启服务 | 配置刷新 |
| `deploy down` | 停止服务 | 关机/暂停 |
| `deploy reset` | 完全重置 | 清理环境 |
| `deploy test` | 测试 API | 验证部署 |
| `deploy open` | 打开浏览器 | 快速访问 |
| `deploy clean` | 清理资源 | 释放磁盘 |

### 原生 Docker 命令

```bash
# 查看所有容器
docker ps -a

# 查看特定服务日志
docker logs -f fde-mate-api

# 进入容器调试
docker exec -it fde-mate-api sh

# 重启单个服务
docker restart fde-mate-api

# 查看网络
docker network ls

# 查看资源使用
docker stats
```

### 数据库操作

```bash
# 进入 MySQL
docker exec -it mysql-8.0 mysql -uroot -p20260227

# 查看数据库
docker exec mysql-8.0 mysql -uroot -p20260227 -e "SHOW DATABASES;"

# 备份数据库
docker exec mysql-8.0 mysqldump -uroot -p20260227 fde_workbench > backup.sql

# 恢复数据库
docker exec -i mysql-8.0 mysql -uroot -p20260227 fde_workbench < backup.sql
```

## 更新流程

### 标准更新流程

```bash
# 1. 拉取最新代码（如果使用 git）
git pull

# 2. 重新构建并启动（代码已修改）
deploy build

# 3. 验证部署
deploy test

# 4. 查看状态
deploy status
```

### 紧急热修复

```bash
# 1. 修改代码文件

# 2. 快速重启（不重建镜像）
deploy restart

# 注意：仅适用于配置变更，代码变更需要 deploy build
```
